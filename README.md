¡Hola! Soy estudiante de 2º de DAW (Desarrollo de Aplicaciones Web) en ILERNA. 

Este año voy a aprender a:
Programar Backend: Aprender a usar PHP y Java (con herramientas como Spring Boot y Laravel) para crear la lógica de las páginas y hacer que todo funcione bien por dentro.

Diseñar Frontend: Usar JavaScript más avanzado, TypeScript y herramientas como React para crear páginas web dinámicas y modernas.

Subir y organizar mis proyectos en internet (DevOps y Nube): Aprender a usar Docker para empaquetar mis aplicaciones, usar Git y GitHub para guardar mi código y gestionar servidores en la nube.

Diseñar webs bonitas y cómodas de usar: Trabajar con CSS y herramientas como Tailwind CSS o Bulma para que las páginas se adapten bien a móviles y ordenadores.

Guardar y organizar la información (Bases de datos): Trabajar con bases de datos como MySQL, PostgreSQL y MongoDB para almacenar toda la información que necesiten mis páginas web.
